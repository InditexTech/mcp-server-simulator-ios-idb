# v2.0.0

_Released November 19, 2026._

The first release since 1.0.1. It fixes most of the natural-language
commands, adds foldable-iPhone support and moves the toolchain to Node 24 and
the new Homebrew `idb` package. The toolchain change is why this is a
major release.

## Changes

### Toolchain: Node 24 and the `meta/fb` Homebrew tap

The package now requires Node.js 24.22.1 or later and npm 12.2.0 or later.
The installer uses the unified `idb` formula from the `meta/fb` tap
(`facebook/fb` was renamed). Python and `fb-idb` now come from Homebrew, so
the project no longer needs its own virtual environment. See [#73](https://github.com/InditexTech/mcp-server-simulator-ios-idb/issues/73).

### Support foldable simulators (iPhone Duo)

Set and read back the hinge angle, inspect the posture, and capture the
active panel, a specific panel or all panels as labelled PNGs. See
[#82](https://github.com/InditexTech/mcp-server-simulator-ios-idb/issues/82).

### Faster device checks

Simulator-only `idb` checks are cached and duplicate `simctl` listings
are gone. Screenshots no longer leave temporary files in the working
directory. See [#101](https://github.com/InditexTech/mcp-server-simulator-ios-idb/issues/101).

### Integration tests against a real simulator

An opt-in suite (`npm run test:integration`) drives the server over MCP
against a disposable simulator. See [#76](https://github.com/InditexTech/mcp-server-simulator-ios-idb/issues/76).

## Fixes

- The MCP server exposes its tools again, and most instructions run the
  operation they name ([#58](https://github.com/InditexTech/mcp-server-simulator-ios-idb/issues/58), [#72](https://github.com/InditexTech/mcp-server-simulator-ios-idb/issues/72)).
- `create session` matches the device name instead of booting a random
  simulator ([#59](https://github.com/InditexTech/mcp-server-simulator-ios-idb/issues/59)).
- `install app` returns the bundle ID that `idb` reports
  ([#89](https://github.com/InditexTech/mcp-server-simulator-ios-idb/issues/89)).
- Screenshots come back as MCP image content instead of a Buffer serialized
  as JSON ([#95](https://github.com/InditexTech/mcp-server-simulator-ios-idb/pull/95)).
- App-listing failures are reported instead of treating the app as missing
  ([#94](https://github.com/InditexTech/mcp-server-simulator-ios-idb/pull/94)), and verification instructions reach
  `isAppInstalled` and `isSimulatorBooted` ([#93](https://github.com/InditexTech/mcp-server-simulator-ios-idb/pull/93)).
- Accessibility description, video recording and the debug server are
  implemented ([#92](https://github.com/InditexTech/mcp-server-simulator-ios-idb/issues/92)).

The full list is in [CHANGELOG.md](../../CHANGELOG.md#200---2026-11-19).

## Migration steps

1. Upgrade to Node.js 24.22.1+ and npm 12.2.0+.
2. If `idb` was installed from the old `facebook/fb` tap, remove it once
   before reinstalling: `brew uninstall idb idb-cli idb-companion`. The
   installer stops and prints this command when it finds the old tap.
3. Run `npm ci` again. The old project venv is no longer used: deactivate it
   and make sure Homebrew's `bin` directory is on the `PATH` of your terminal
   and MCP host.
