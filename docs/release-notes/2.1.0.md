# v2.1.0

_Released November 24, 2026._

The server can now drive **tvOS simulators** with the same `idb` and
`xcrun simctl` setup it already uses for iOS, with no new dependencies.

## Changes

### Support tvOS simulators

- `create session` still prefers iOS when no platform is given. Pass `tvOS`
  as the platform version to get an Apple TV simulator. Unavailable
  simulators are skipped.
- New `press remote up|down|left|right|select|menu` instruction for the Siri
  Remote (English and Spanish, optional duration). `press device button` now
  accepts all nine `idb` buttons, including `PLAY_PAUSE`, `VOLUME_UP`,
  `VOLUME_DOWN` and `EJECT`.
- `describe all elements` and `describe point` report whether an element is
  `focused` and `enabled`. New `tap element "<label>"` and
  `tap element with id "<id>"` instructions tap an element by its
  accessibility label or identifier.
- Coordinate taps and swipes, hinge and orientation fail fast on tvOS with a
  message explaining what to use instead.

macOS is not supported: CoreSimulator has no macOS simulator.

See [#19](https://github.com/InditexTech/mcp-server-simulator-ios-idb/issues/19) and [#108](https://github.com/InditexTech/mcp-server-simulator-ios-idb/pull/108).
