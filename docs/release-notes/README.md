# Release notes

What each minor and major release means for users: what's new, what changed
and how to upgrade. Patch releases are only listed in
[CHANGELOG.md](../../CHANGELOG.md).

Pages are seeded from the changelog by `npm run release:prepare` (or
`node .github/scripts/release-notes-seed.mjs X.Y.Z --write`) and then written
by hand. See [CONTRIBUTING.md](../../CONTRIBUTING.md#releases).
